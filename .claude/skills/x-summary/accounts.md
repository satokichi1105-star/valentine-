# 監視アカウントリスト

Claude Code の使い方・スキル・新機能・Tips を追うためのXアカウント。
優先度は `tier` で表す。サマリー生成時、tier 1 は必ず巡回し、tier 3 は情報量が
足りないときの補助として使う。

このファイルを書き換えればサマリーの対象が変わる。アカウントを増やすときは
`@` 付きハンドルと一言の説明を添えること。
